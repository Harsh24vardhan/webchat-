🔔 Dynamic Notification Badge Demo

Real-time unread message counter

✨ How It Works

Automatic Badge Updates: The notification badge now displays the actual count of unread messages, just like WhatsApp, Telegram, or Messenger!

• When chat is closed and bot sends messages → Badge count increases

• When you open the chat → Badge clears to 0

• Shows up to 99, then displays "99+"
